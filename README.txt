PACER 웹사이트 (수정본)

구조: BRAND (메인 배너 4장 포함) → CITIES → COMMUNITY → STORE, 총 4개 풀페이지 섹션.

준비할 이미지:
- assets/pacer_logo.png  (좌상단 로고)
- assets/main_banner01.jpg (중앙에 겹치는 러닝 사진)
- assets/main_banner02.jpg (두 번째 슬라이드 이미지)
- assets/main_banner03.jpg (세 번째 슬라이드 이미지)

첫 번째 배너의 큰 빨간 RUN AT YOUR / PACE 글자는 CSS의 .hero-type에서 실시간 텍스트로 구성됩니다.
제공된 디자인 캡처에는 실제 사진 원본이 포함되어 있지 않아 이미지 파일은 별도로 넣어야 합니다.
네 번째 배너는 START YOUR PACE 임시 타이포그래피 화면입니다.

폰트: Pretendard CDN, KIMM_Bold CDN, Microsport 로컬 파일 (fonts/Microsport.woff2).
Microsport는 웹 사용 라이선스와 파일이 필요합니다. 유료 폰트를 ZIP에 포함하지 않았습니다.

실행: VS Code Live Server에서 index.html 실행. 인터넷 연결 필요(Swiper/CDN).
